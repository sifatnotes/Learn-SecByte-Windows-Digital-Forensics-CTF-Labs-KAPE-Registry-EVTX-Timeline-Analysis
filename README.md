# Windows Digital Forensics & Artifact Analysis CTF Labs

A curated index of [Learn SecByte cybersecurity labs](https://learn.secbyte.org/ctf/) focused on Windows digital forensics, system artifacts, event log analysis, timeline reconstruction, and evidence collection.

This repository is designed for digital forensics learners, SOC analysts, incident responders, CTF participants, and cybersecurity students.

## Introduction

Windows systems preserve many artifacts that can help investigators understand system activity. Event logs, registry data, file system metadata, application execution traces, and shortcut records can contribute to an investigation when interpreted in context.

These labs offer a structured starting point for exploring Windows forensic artifacts and investigation workflows in authorized environments.

## Learning Path

1. Start with event log investigation using the Chainsaw and EVTXCmd labs.
2. Explore Prefetch, Amcache, and Shimcache artifacts.
3. Investigate LNK files, Jump Lists, and ShellBags for user-activity clues.
4. Examine registry and MFT artifacts.
5. Use the timeline exercise to practice organizing evidence chronologically.
6. Finish with the KAPE evidence collection lab and document your workflow.

## How to Use the Labs

1. Open a lab using its direct link.
2. Follow the provider's instructions and permitted scope.
3. Work with the supplied evidence or authorized lab environment.
4. Record artifact locations, timestamps, findings, and uncertainties.
5. Correlate multiple sources rather than relying on a single artifact.
6. Document conclusions and preserve evidence integrity.
